Este projeto, é um repositório de caráter educacional focado no aprendizado de ferramentas de versionamento e fundamentos de desenvolvimento.


1. Contexto Acadêmico
O projeto faz parte das atividades práticas do curso de Back-end da EBAC (Escola Britânica de Artes Criativas e Tecnologia). Ele serve como um exercício inicial para consolidar o uso do Git em um ambiente de desenvolvimento.

2. Objetivos e Práticas de Git
O foco principal deste repositório não é o código em si, mas sim a execução do fluxo de trabalho (workflow) do Git, incluindo:

Versionamento: Criação e manutenção de um repositório remoto no GitHub.

Gerenciamento de Branches: Uma das tarefas explícitas descritas no documento foi a criação de uma nova branch, técnica essencial para desenvolver funcionalidades de forma isolada antes de integrá-las ao projeto principal.

Documentação Inicial: O uso do arquivo README para identificar o propósito do projeto e a instituição de ensino.

3. Conteúdo Técnico
O repositório é um ponto de partida para aulas de Back-end, preparando o terreno para projetos futuros que envolverão lógica de servidor, bancos de dados ou APIs, utilizando o Git como a ferramenta base para organizar essas entregas.

Em resumo, trata-se de um projeto de fundamentos de infraestrutura de desenvolvimento, focado em aprender como organizar e subir códigos profissionalmente utilizando branches e comandos Git.
